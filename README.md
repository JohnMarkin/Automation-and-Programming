# ETF-Based Robo-Advisor Using Black-Litterman and Monte Carlo Simulation
Designed and implemented a robo-advisor leveraging Modern Portfolio Theory (MPT) to construct optimal ETF-based portfolios along the Efficient Frontier.
Applied Wealthfront-inspired methodology for asset selection using cost-effective ETFs with low expense ratios, high liquidity, and minimal tracking error.
Integrated web scraping tools to extract real-time ETF data (e.g., expense ratio, trading volume) from Yahoo Finance for dynamic portfolio construction.
Utilized the Black-Litterman model and CAPM for forward-looking return estimation; incorporated Monte Carlo simulations to model market uncertainty.
Benchmarked asset classes against major indices (e.g., S&P 500, FXNAX) and included commodities for inflation protection and diversification benefits.
